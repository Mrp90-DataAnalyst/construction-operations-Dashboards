## What's Inside

### 1. Financial Controls Dashboard
Transaction-level verification and expense monitoring that mimics ERP posting controls.

- **KPI Summary** — Contract value, collections, expenses, and net cash position
- **Account Verification System** — Every transaction tracked as Verified / Pending / For Review with OR/Invoice/PCV references
- **Sensitive Transaction Alerts** — Petty cash and executive withdrawals flagged until receipts are attached
- **Expense Analytics** — Monthly trends, category breakdowns, and per-project spending

### 2. ManCom Report Dashboard
Executive-level reporting designed for management committee / board meetings.

- **Executive Snapshot** — 6 key financial indicators at a glance
- **Monthly P&L** — Earned vs. spent, with spending breakdown by category
- **Balance Sheet** — What the company has, owes, and owner's equity
- **Project Status** — Billing vs. accomplishment tracking with slippage indicators
- **Financial Health Check** — 7 plain-English questions with OK / WATCH / CHECK status indicators
- **Cost Distribution** — Cost logged by project and expense category matrix

## How It Works

These dashboards are generated from structured Excel workbooks — no database, no server, no monthly software subscription.

```
Excel Workbook → Python Script → Interactive HTML Dashboard
```

The system includes:
1. **Structured Excel workbook** with project registry, receivables tracker, and expense ledger with ERP-style account verification
2. **Automated dashboard generation** via a lightweight Python script
3. **Management-ready HTML output** that opens in any browser — shareable via email, link, or print

## Who This Is For

Small to mid-size construction businesses that:
- Track finances in Excel or paper notebooks
- Need internal controls but can't justify ERP software costs
- Want owner/board-ready reporting without hiring a full-time analyst
- Handle multiple concurrent projects with subcontractors and milestone-based billing
